# Лесной сапёр

Дружеский браузерный сапёр во вселенной «Лесной сферы»: общее поле, поиск мин,
очки за точные догадки, штрафы за подрыв и свободный режим с лесным духом.

## Правила

- Поле 16 × 16, в нём 33 мины.
- Можно позвать до 19 друзей по 6-символьному коду комнаты.
- Нажатия разрешаются сервером по порядку прихода. Одна клетка меняется только один раз.
- У каждого участника есть 17 попыток с флажком за партию. Правильный флажок первым
  находит мину, открывает её всем и приносит игроку 2 очка.
- Неверный флажок виден только его автору. Попытка расходуется; повторное нажатие снимает
  флажок, но не возвращает попытку.
- Если открыть мину вместо флажка, она становится видна всем, а игрок теряет 3 очка.
- Безопасные клетки и пустые области открываются для всех; подсказки в них общие.
- Матч завершится, когда найдены все мины. Побеждает игрок с наибольшим счётом.
- В одиночном режиме лесной дух играет с тем же полем и лимитом флажков.

Код комнаты даёт право войти: передавайте приглашение только друзьям. Пока что вход
не требует учётной записи, и сервер не закрепляет за игроком подтверждённое имя.

## Публикация бесплатно

Игра поделена на две части: GitHub Pages размещает файлы интерфейса, а Cloudflare
Worker хранит состояние комнат и подтверждает действия через WebSocket и SQLite
Durable Objects. Бесплатные тарифы подходят для небольших дружеских партий, но имеют
общие ограничения по дневному объёму работы. При превышении лимитов новые действия
могут перестать проходить до сброса квоты.

### Один раз опубликовать сервер комнат

1. Установить Node.js и Git, установить Wrangler: `npm install --global wrangler`.
2. `cd worker`, выполнить `npm install`.
3. Выполнить `npx wrangler login` и самостоятельно подтвердить Cloudflare в браузере.
4. Выполнить `npm run deploy`. На бесплатном аккаунте будет опубликован Worker
   `forest-mines-rooms` с привязкой SQLite Durable Objects.
5. Скопировать адрес Workers, который печатает Wrangler, например
   `https://forest-mines-rooms.<поддомен>.workers.dev`.

В Cloudflare Workers нужно включить workers.dev для своего аккаунта. Публикация
создаёт новый Worker и пространство Durable Objects в выбранном Cloudflare-аккаунте.

### Опубликовать страницу

1. В корне проекта выполнить `node scripts/set-worker-url.mjs https://...workers.dev`
   с адресом только что созданного Worker.
2. Создать новый **публичный** GitHub-репозиторий для этого проекта и отправить ветку
   `main` вместе с `.github/workflows/pages.yml`.
3. В настройках репозитория выбрать **Settings → Pages → Build and deployment →
   Source: GitHub Actions**.
4. Дождаться запуска `Publish Forest Mines` и открыть ссылку GitHub Pages.

Если нужно сменить Worker, обновите URL той же командой и отправьте изменение в `main`.

## Разработка

- Интерфейс: `public/` — статические HTML, CSS и JavaScript, без сборщика.
- Сервер: `worker/src/index.ts` — Durable Object на каждую комнату.
- Параметры Worker: `worker/wrangler.jsonc`.
- Локальная версия Worker: `cd worker; npm install; npm run dev`.
- Игроки получают только открытые клетки. Размещение остальных мин и право менять очки
  остаются на сервере. Список всех комнат игрокам не показывается.

Код комнаты состоит из шести случайных символов и является приглашением, а не паролем.
Текущий прототип не предлагает публичный каталог матчей, голосовой чат, вход в аккаунт,
сохранение рейтинга после окончания партии или восстановление комнаты спустя шесть часов
после выхода всех игроков.
